# THE UNKNOWN — 3D SCIENCE OBSERVATORY

A cinematic interactive 3D science website built with:

- HTML
- CSS
- JavaScript
- Three.js
- WebGL

Designed for static GitHub Pages hosting.

---

## PROJECT

THE UNKNOWN is an interactive science observatory exploring:

- Solar System
- Planets
- Earth
- Moon
- Artificial satellites
- Asteroid belt
- Black holes
- DNA
- Quantum concepts
- Artificial intelligence

---

## FEATURES

### 3D ENGINE

The project uses Three.js through an ES module import map.

### SOLAR SYSTEM

Includes:

- Sun
- Mercury
- Venus
- Earth
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune
- Planetary orbital motion
- Planet rotation
- Moon
- Artificial satellite
- Saturn rings
- Asteroid belt
- Deep-space starfield

Planet sizes and distances are intentionally compressed so the complete scene can be explored interactively on a phone.

---

### BLACK HOLE

Includes a conceptual 3D black-hole visualization with:

- Dark central core
- Accretion-disk-inspired rings
- Particle field
- Additional orbital rings

This is a visual educational model, not a relativistic physics simulation.

---

### DNA / LIFE

Includes a 3D double-helix visualization inspired by DNA structure.

---

### QUANTUM

Includes an artistic visualization inspired by:

- Probability
- Quantum states
- Superposition concepts
- Complex orbital motion

This is not a physical quantum simulation.

---

### AI CORE

Includes a 3D neural-network-inspired visualization showing:

- Input layer
- Hidden layers
- Output layer
- Connected nodes

It is a visualization of the idea of layered computation, not a real machine-learning training system.

---

## CONTROLS

### Desktop

- Drag → orbit camera
- Mouse wheel → zoom
- Right mouse → pan
- Click object → inspect

### Mobile

- One finger → orbit
- Pinch → zoom
- Tap object → inspect

---

## UI CONTROLS

### AUTO ORBIT

Automatically rotates the camera around the current scene.

### RESET VIEW

Returns the camera to the recommended position for the current scene.

### QUALITY

Cycles through:

- AUTO
- HIGH
- LOW

Use LOW on devices where the scene becomes slow.

### AMBIENCE

Creates a short minimal ambient tone using the browser's Web Audio API.

No audio starts automatically.
